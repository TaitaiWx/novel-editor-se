# 素材预览与版本对比样例

这个目录放了成对的媒体文件（`xxx` 与 `xxx-alt`），用来体验「资料预览」和「版本历史对比」。

## 预览

在左侧「资料」里直接点开即可：

- `场景分镜.svg`、`场景截图.png`：图片预览
- `章节地图.pdf`：PDF 页缩略图与翻页
- `环境音.wav`：音频播放器与时长等信息
- `二进制样本.bin`：无法预览的文件显示通用的文件信息面板

## 版本对比（推荐流程）

1. 打开任意主文件，例如 `场景截图.png`
2. 在版本历史里点「保存版本」
3. 用对应的 `-alt` 文件替换主文件（例如把 `场景截图-alt.png` 复制一份，改名覆盖 `场景截图.png`）
4. 再次「保存版本」
5. 点击旧版本，查看并排对比 / 差异

| 主文件 | 对比文件 | 体验点 |
