## 目录

- `规则.json`：属性、等级经验曲线、技能、二选一/三选一、核心规则、战力限制

- `队伍.json`：曾经组过的队伍、配角最近出场章节
- `地图.json`：地点与到访记录
- `角色卡/`、`设定/`：从编辑器数据库同步的人物卡与设定快照（只读）
