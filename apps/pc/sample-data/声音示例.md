## 场景视频里的声音

这场戏已经预先做成了一场场景视频，不需要任何 AI Key 就能打开看完整流程：

- 打开方式一：左侧「资料 → 视频 → 001-启程」，单击带场景标记的「第一场 清晨的青石镇」，直接打开它的画布
- 打开方式二：打开 `novels/星河旅人/第一卷-离乡/001-启程.md`，把光标放在「第一场」里，点文件栏的「场景视频」
- 画布上：5 个镜头，带「台词 N」「音效 N」「配乐」标记；镜头 1、2 已有成片，镜头 1 还有 3D 预演；最右边是带声音的样片

每一种声音在哪里改：

| 声音 | 在哪里改 | 说明 |
| --- | --- | --- |
| 对白 | 单击镜头 → 检查器「对白」 | 说话人（出场人物或旁白）、台词、情绪、开始时间（相对镜头起点，不填就紧接上一句） |
| 配音 | 同上，每句「生成配音」/ 试听 | 需要在设置中心配置配音服务；文件保存为 `镜头N-台词-<id>` |
| 语言 | 单击场景 → 检查器「声音 → 配音语言」 | 默认取设置中心「配音默认语言」，例如普通话、英语 |
| 配乐 | 场景检查器「背景音乐」 | 选 `资料/音乐/` 里的文件，调音量、淡入淡出；对白时可以自动压低 |
| 环境音 | 场景检查器「环境音」 | 文件或文字描述（交给能生成声音的视频服务） |
| 音效 | 镜头检查器「音效」 | 描述或 `资料/音效/` 里的文件、时间点、音量 |
| 人物音色 | 人物详情 →「人物设计」底部的「声音」 | 性别、年龄、音色描述，配音时自动带上 |

合成样片时，对白按镜头起点 + 开始时间排开，音效落在各自的时间点，配乐铺满整场并在对白处压低约 12dB，环境音循环垫底。
