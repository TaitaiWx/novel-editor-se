# 欢迎使用小说编辑器

这是一份完整的示例作品集，每个功能都放了能直接上手的样例。随便改、随便删都没关系——它是你「文稿/Novel Editor/sample-data」里的一份副本，不会影响安装包里的原始示例。

## 目录一览

| 位置 | 是什么 |
| --- | --- |
| `novels/星河旅人/` | 主示例：一部 6 章的冒险小说，分两卷 |
| `novels/星河旅人/资料/` | 这部作品的设定笔记（世界观、势力、名词表） |
| `novels/星河旅人/资料/记忆/` | 这部作品的成长档案：规则之书、角色成长卡、队伍、地图 |
| `novels/星河旅人/资料/素材/` | 图片 / PDF / 音频 / 二进制，用来体验预览与版本对比 |
| `novels/星河旅人/资料/文档示例/` | Word / PowerPoint / Excel 文件 |
| `novels/剑与诗/` | 第二部作品：2 章武侠短篇，有自己的人物、设定与资料 |
| `novels/剑与诗/资料/` | 《剑与诗》自己的设定笔记与成长档案 |
| `.novel-editor/` | 项目配置（`ne init` 生成的同款结构），一般不用管 |

**角色、设定、成长档案、资料都跟随作品**：每部作品的资料放在作品目录下自己的「资料」文件夹里，人物卡和设定也按作品分开保存。左侧文件面板顶部的「当前作品」可以切换作品（或新建作品），下面的正文、角色、设定、成长档案、资料只显示当前这部作品；打开另一部作品的章节时会自动切过去。这份说明和 `排版示例.md` 这类不属于任何作品的文档，收在面板最底部默认折叠的「项目说明」里。

## 1. 正文：卷与章

1. 在左侧顶部的「当前作品」选择「星河旅人」，展开「第一卷-离乡」，打开 `novels/星河旅人/第一卷-离乡/001-启程.md`
2. 直接打字：停笔 2 秒自动保存，⌘Z / Ctrl+Z 撤销，状态栏实时显示字数
3. 文件夹即「卷」，文件名前的数字决定章节顺序；右键可以新建、重命名、删除

## 2. 幕剧与大纲

1. 打开 `novels/星河旅人/第一卷-离乡/003-狼王之夜.md`，点右上角展开右侧面板
2. 切到「卷规划」：正文里的「第三幕 / 第一场 / 第二场…」会变成幕剧卡片，点卡片跳到对应段落
3. 回到 `novels/星河旅人/第一卷-离乡/001-启程.md` 切到「本章大纲」：已经写好两条章纲；「目录」则按标题自动生成
4. 选中左侧的卷或项目，按钮会变成「本卷大纲」/「作品大纲」（示例预置了两卷的作品大纲和第二卷的卷纲）

## 3. 人物与设定

1. 左侧文件面板的「角色」右键 →「查看详情」：《星河旅人》的林舟、苏晴、白鸦、秦伯、小石头 5 个人物卡
2. 「设定」右键 →「查看详情」：星河大陆、星港城商会、星图碎片等设定条目
3. 把「当前作品」切到「剑与诗」：角色变成沈砚与听雨楼诗人，设定变成听雨楼等，互不混在一起
4. 正文里出现的人物名会按人物卡设置的颜色高亮，方便扫读

## 4. 成长档案与记忆库

专为「写了几百章，忘了当初的设定」准备：

1. 左侧「成长档案」分区里点「林舟」：等级、经验、属性、技能、三选一的道途抉择，以及每一章的成长记录
2. 点「记一笔」，写下本章获得的经验，升级与属性成长自动计算
3. 「世界」页签：队伍历史（`novels/星河旅人/资料/记忆/队伍.json`）、地图足迹（`novels/星河旅人/资料/记忆/地图.json`）、核心规则（`novels/星河旅人/资料/记忆/规则.json`）
4. 秦伯已经 5 章没出场了——示例特意保留了这条「被遗忘的配角」提醒，打开 `novels/星河旅人/资料/记忆/README.md` 也能看到
5. 「推演」：把二选一 / 三选一扔给 AI，看角色自动成长一段时间后的结果（需要先在设置里配置 AI）

所有成长数据都是作品「资料/记忆」文件夹里的 JSON 文件（《剑与诗》有自己的一份：`novels/剑与诗/资料/记忆/`），GUI、命令行和 AI 读写的是同一份。

## 5. 资料与素材预览

- 点开 `novels/星河旅人/资料/世界观.md`、`novels/星河旅人/资料/势力与组织.md`、`novels/星河旅人/资料/名词表.md` 查看设定笔记
- 点开 `排版示例.md` 体验 Markdown 实时渲染：标题、表格、公式就地显示，光标移进去即可编辑源码
- 点开 `novels/星河旅人/资料/素材/场景截图.png`、`novels/星河旅人/资料/素材/章节地图.pdf`、`novels/星河旅人/资料/素材/环境音.wav` 体验图片、PDF、音频预览

## 6. 版本历史与对比

按 `novels/星河旅人/资料/素材/README.md` 的步骤：先给 `novels/星河旅人/资料/素材/场景截图.png` 保存一个版本，再用 `novels/星河旅人/资料/素材/场景截图-alt.png` 替换它并再保存一次，然后点旧版本查看并排对比。正文章节同样可以保存版本、查看文字差异。

## 7. 导入导出 Word / PPT / Excel

- 直接打开 `novels/星河旅人/资料/文档示例/编辑器介绍.docx`、`novels/星河旅人/资料/文档示例/编辑器介绍-幻灯片.pptx`、`novels/星河旅人/资料/文档示例/表格示例.xlsx` 预览内容
- `novels/星河旅人/资料/文档示例/损坏的文档.docx` 是一个故意损坏的文件，用来展示打不开时的提示
- 菜单「文件 → 导出项目…」（⇧⌘E / Ctrl+Shift+E）可以把整个项目导出到其他位置

## 8. AI 助手

AI 功能默认关闭。打开「设置中心」（⌘, / Ctrl+,），在 AI 分区填入服务地址与 Key 后即可使用：续写、润色、提取人物与设定、成长推演等。

## 9. 命令行 ne

示例目录就是一个标准的 `ne init` 项目，在终端里进入这个文件夹即可：

```bash
ne status                       # 项目概况：作品、字数、今日写作
ne novel list                   # 列出作品：星河旅人、剑与诗
ne chapter list 星河旅人         # 按卷列出章节
ne stats 星河旅人                # 字数、段落统计
ne growth list --novel 星河旅人   # 成长档案跟随作品：林舟 Lv.4、苏晴 Lv.3
ne growth list --novel 剑与诗     # 《剑与诗》自己的成长卡：沈砚
ne growth check --novel 星河旅人  # 战力一致性检查 + 被遗忘的配角
ne file search 星图碎片          # 全文搜索
```

所有命令都支持 `--json`，方便交给 AI agent 调用。

---

看完就可以开始写自己的故事了：「文件 → 打开文件夹…」打开你的作品目录，或在终端执行 `ne init 我的小说` 新建一个项目。
