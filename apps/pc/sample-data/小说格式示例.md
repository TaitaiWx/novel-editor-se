# 小说格式示例

这一篇演示「小说格式」的写法：仍然是普通的 Markdown，只多了几行「指令」。不认识这些写法的工具会把它们当作普通文字显示，不会丢内容。

开头的 `---` 之间是本章信息（视角、状态等），不计入字数。

:::scene{#s-demo-1 title=港口 pov=林舟 location=星港城 time=黄昏}
林舟背起行囊，最后看了一眼灯塔。

码头上停满了船，桅杆像一片森林。
:::

:::scene{#s-demo-2 title=夜航 location=货船 time=深夜}
船离港时，苏晴把星图摊在甲板上。
:::

上面两段各是一场：以 `:::scene{…}` 开始、单独一行 `:::` 结束。卷纲与目录会把它们识别为「场景」，光标不在这一行时显示为场景条。

视频用一行 `::video` 引用，路径相对作品目录；单击视频卡片会在编辑器旁边的参考窗格里播放：

::video[林舟离港]{src="资料/视频/示例/离港.mp4"}

（这里是示例路径。用「场景视频」生成成片后，把 src 换成 资料/视频/ 下的真实文件即可。）

命令行可以检查格式是否正确：`ne lint`。
